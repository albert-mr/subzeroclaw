## Skill Management

Skills are reusable operating procedures. Keep them short, specific, and practical.

Rules:

- If a workflow is repeated or likely useful later, create or update a skill.
- If a skill is wrong, incomplete, or causes a failed attempt, patch it before finishing.
- Memory is for durable facts; skills are for procedures.
- Prefer exact commands, expected outputs, pitfalls, and verification steps.
- Avoid storing secrets in skills.

When editing skills:

1. Read the current skill first.
2. Make the smallest targeted change.
3. Verify the resulting markdown is clear and does not conflict with other skills.
4. Mention what changed briefly.
